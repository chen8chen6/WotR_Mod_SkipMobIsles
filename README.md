# WotR_Mod_SkipMobIsles

Allow players to skip mob isles and land on the Boss isles directly.
Players still get xp, golds and unique items(non-unique items are converted into golds) from the isles they fast traveled through, so our lovely [Rope of the Seven Sins] and [Ring of Triumphant Advance] won't be lost.

# Preview:

https://www.bilibili.com/video/BV1pWhi6HEHG/

# Installation:

Method 1:

1. Create a new folder named "SkipMobIsles" under the game mod folder(ex: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\Mods\).

2. Unzip the files of "SkipMobIsles.zip" into the folder you just created.


-- OR --


Method 2:

1. Download and install the UnityModManager

2. Start UnityModManager. Select "Pathfinder: Wrath of the Righteous" for game label. Select game installtion path(ex: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\) for folder label. Click "Install" button.

3. Click "Mods" label on top, then click "Install Mods" button. Select "SkipMobIsles.zip".

# WotR_Mod_SkipMobIsles

可跳过杂兵岛直接登陆Boss所在岛屿, 同时获取途中的xp, 金币和独特物品(非独特物品折算成金币). 所以丢不了七罪法袍和高奏凯歌戒指.

# 效果预览:

https://www.bilibili.com/video/BV1pWhi6HEHG/

# 安装:

方法1:

1. 在游戏mod目录(例: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\Mods\)下创建新文件夹, 命名为SkipMobIsles

2. 将压缩包内文件解压到该目录下.


-- 或者 --


方法2:

1. 下载并安装UnityModManager.

2. 启动UnityModManager, Game栏选择Pathfinder: Wrath of the Righteous, Folder栏选择游戏安装目录(例: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\), 然后点击"Install"按钮.

3. 点击上方"Mods"标签, 选择"Install Mods", 在弹出的对话框中选择"SkipMobIsles.zip"
